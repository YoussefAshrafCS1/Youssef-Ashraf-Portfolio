About

I'm a Computer Science student at Ain Shams University in Cairo, specializing in full-stack .NET development. My work spans C#, ASP.NET Core, and SQL Server on the web side, with a foundation in data structures, object-oriented programming, and applied machine learning.

I learn by building: a loan-approval model trained with Scikit-learn, a line-tracking robot running on embedded C and IR sensors, an inventory system written in Java. Each project pushed me to think past the code, toward what the system actually needs to do for the people using it.

I'm looking to bring that same practical approach to small businesses and startups that need software built right the first time, without the overhead of a large agency.
